# Projeto Vassoural — site

Site do Projeto Vassoural (Louveira, SP): aulas gratuitas de jiu-jítsu e inglês para crianças e arrecadação de alimentos.

- **Versão pública:** abra o site normalmente.
- **Prévia da equipe:** acrescente `?previa=1` ao endereço para ver os blocos que ainda dependem de validação.
- **O que falta validar:** `pendencias.html?previa=1`
- **Como atualizar:** ver [COMO-ATUALIZAR.md](COMO-ATUALIZAR.md). Quase tudo fica em `js/dados.js`.
- **Decisões de design:** ver [DESIGN.md](DESIGN.md).

Site estático (HTML, CSS e JS), sem etapa de build. Publicado pelo GitHub Pages a partir da branch `main`.
